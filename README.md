# 🚗 Online Car Rental Management System

A web-based car rental management system developed using PHP and MySQL.

## ✨ Features

- User registration and login
- User profile management
- Car listing
- Car details
- Car availability checking
- Online car booking
- Booking management
- Invoice generation
- Customer testimonials
- Contact form
- Admin management

## 🛠️ Technologies

- PHP
- MySQL
- HTML5
- CSS3
- JavaScript
- Bootstrap
