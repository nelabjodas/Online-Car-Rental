# 🚗 Online Car Rental Management System

A web-based car rental management system developed using **PHP and MySQL**. The application provides vehicle listings, availability checking, online booking, user management, invoice generation, testimonials, and administrative functionality.

## ✨ Features

### User Features

- User registration and login
- User profile management
- Password update
- Vehicle listing
- Vehicle details
- Vehicle availability checking
- Online car booking
- Booking history
- Invoice generation
- Customer testimonials
- Contact form

### Admin Features

- Admin authentication
- Vehicle management
- Vehicle inventory management
- Booking management
- User management
- Testimonial management
- Contact/query management
- Page/content management
- Invoice settings

## 🛠️ Technologies Used

- **PHP**
- **MySQL**
- **HTML5**
- **CSS3**
- **JavaScript**
- **Bootstrap**
- **XAMPP** for local development
